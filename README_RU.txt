GESTURE LAB — ЧАСТЬ МЕДИНЫ

Запуск на Windows (Python 3.12):
1. Распакуйте архив в отдельную папку.
2. В этой папке откройте терминал (можно ввести cmd в адресной строке Проводника).
3. Выполните: python -m venv .venv
4. Выполните: .venv\Scripts\activate
5. Выполните: python -m pip install -r requirements.txt
6. Выполните: python -m streamlit run app.py
7. Откройте адрес localhost, показанный в терминале. Интернет нужен для установки;
   после установки приложение использует включённые веса без их скачивания.
START_WINDOWS.bat работает, если нужное Python-окружение уже активно.

Приложение: загрузка JPEG/PNG, снимок с камеры (не потоковое видео), выбор модели,
оценки трёх классов, Grad-CAM, время прямого прохода, сохранение тепловой карты,
таблица сравнения, графики обучения и матрицы ошибок. Примеры взяты из validation.
Низкая уверенность — только предупреждение, а не обученный класс «неизвестно».

Повторное обучение:
Рядом с папкой проекта разместите готовую папку Gesture_A2_Data из предыдущего архива.
python train.py --data ../Gesture_A2_Data
python check_and_stress.py
Нужен интернет для загрузки ImageNet-весов при первом обучении.
Веса и таблицы будут перезаписаны. Перед новым запуском сохраните прежние результаты.

ПРОТОКОЛ
Обе модели: ImageNet backbone заморожен, batch normalization в eval.
Размер 160x160, серое дополнение с сохранением формы, ImageNet mean/std.
Train: оригинал + одна воспроизводимая случайная версия каждого изображения
(flip, affine, brightness/contrast); features вычислены один раз и переиспользуются.
Это фиксированная аугментация, не новые изображения в каждой эпохе.
40 эпох классификатора, Adam lr=0.001, batch=32, seed=42; лучшая эпоха по val loss.
ResNet18 имеет линейный head; MobileNetV2 — dropout 0.2 и линейный head.
Это новые стандартизированные reference runs A2, не точное повторение A1.
В частности, MobileNetV2 здесь не fine-tuned, а ResNet18 использует 160 вместо 224.
Не называйте сравнение доказательством эффекта только архитектуры или нового SOTA.
Test не использовался для выбора эпохи; дополнительно проверен на фиксированных
искусственных искажениях. Яркость 50% и Gaussian blur radius 2 не являются
реальными размеченными условиями съёмки. Фоновый stress-test ещё нужен на новых фото.
Латентность: среднее 20 warmed CPU forwards; без декодирования, preprocessing и CAM.
На ноутбуке время будет другим. Показатель в приложении измеряется заново.

ЧТО ЕЩЁ НУЖНО ОТ АЙГАНЫМ
Новый SOTA-компонент, его модель/результаты и ablation; описание метода; демовидео.

содержит готовую часть Медины, которую можно открыть в браузере и скопировать в Word.

ОГРАНИЧЕНИЯ И ЭТИКА
Участники не полностью идентифицированы; split не гарантирует независимость по людям.
Не все похожие кадры могут быть найдены. Данные раньше использовались в A1.
Одно разбиение и один seed; маленькая выборка. Оценки не доказывают работу на новых людях.
Три известных класса: любые другие изображения тоже получат одну из этих меток.
