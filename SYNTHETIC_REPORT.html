Synthetic-frame ablation — Medina and Aiganym

We received 1026 images: 171 original frames and 855 derived augmentations. Seven source sequences were inferred from filenames. Transition frames with an absent target gesture were excluded. We selected 36 evenly spaced eligible original frames, 12 per class, before training. Derived augmentation copies were not used. Source generator, prompts and seeds were not provided; attribution to Step-Video-T2V or ArtAug is unverified.

Both branches use the same MobileNetV2 ImageNet initialization, seed 42, frozen backbone, input 160, 40 head epochs and minimum validation loss selection. Training has 535 real images versus 535 real plus 36 synthetic (6.3% synthetic before augmentation). Each receives an original and one augmented training view. Validation (114) and test (112) remain real and unchanged. Fixed epochs imply slightly more optimizer steps in the larger training branch. A control run was reproduced in the current environment.

Application

Select mobilenet_v2_synthetic to use the new weights. The app includes Grad-CAM, a camera snapshot, and an interactive brightness/blur stress test. Physical webcam operation still needs checking on the user device. Original MP4s were not provided, so this package does not add video playback or live video tracking.
